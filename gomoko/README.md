## 二、项目简介

本项目使用 Python 面向对象编程，实现了一个支持三人对弈的五子棋游戏。
在传统黑白二人五子棋的基础上增加第三方"红方"：黑、白、红三方按固定顺序
轮流落子，任意一方率先在横、竖、斜任一方向连成五子即获胜；
若棋盘下满仍无人获胜，则判平局。

## 三、功能列表

- 10×10 棋盘，黑(1)、白(2)、红(3) 三方轮流落子
- 落子前自动校验：越界、重复落子均拒绝并给出提示
- 自动判胜：横、竖、两条斜线共四个方向，同色五子连珠即获胜
- 棋盘下满自动判平局，避免程序死循环
- 支持棋局保存与读取（pickle 二进制持久化）
- 控制台棋盘打印：黑 / 白 / 红 / 空 四态显示

## 四、项目结构

代码由四个类组成，遵循"职责单一"的面向对象设计原则：

| 类 | 职责 |
| --- | --- |
| Player 玩家类 | 管理轮到谁下子，负责切换下子方与颜色转换 |
| Board 棋盘类 | 棋盘数据、落子校验、五子判胜、棋盘打印 |
| FileSaveLoad 文件类 | 棋局的保存与读取，与游戏逻辑解耦 |
| Game 游戏类 | 继承上述三个类，组织"读入→落子→判胜→换手"主循环 |

## 五、运行方法

环境要求：Python 3.x，无第三方依赖（仅使用标准库 pickle）。

```bash
python gomoku_3players.py
```

## 六、操作说明

| 输入 | 作用 |
| --- | --- |
| `4,4` | 在第 4 行第 4 列落子（不要打括号） |
| `S` 回车 | 保存当前棋局 |
| `L` 回车 | 读取已保存的棋局 |

## 七、判胜规则

落子后从该子出发，沿水平、垂直、两条斜线共四个方向统计己方颜色的
连续棋子数，任一方向达到 5 个即判胜；对方颜色的棋子会阻断连线。

## 八、设计思路

- 用列表推导式生成棋盘，保证每个格子互相独立，避免列表引用共享问题
- 三个父类各自独立、互不依赖，Game 类通过多继承组合，便于单独测试
- 越界与占用校验全部封装在棋盘类内部，外部调用方无法破坏棋盘状态
